## Gaps Requiring Phase 2 Attention

### FAIL Items (Must Fix)

1. **[US-E0-010] No test coverage for health check and metrics code**: Health routes (`routes/health.ts`), deployment monitoring (`middleware/deployment-monitoring.ts`), and correlation ID middleware (`middleware/correlation-id.ts`) have zero dedicated tests. DoD requires 95%+ coverage. This is a Phase 2 blocker for these modules.

2. **[US-E0-011] No test coverage for CSRF middleware**: `middleware/csrf.ts` has no test file. The middleware is well-implemented (timing-safe comparison, token rotation, proper exclusions) but entirely untested. DoD requires 95%+ coverage.

### PARTIAL Items (Should Fix)

3. **[US-E0-009] `docker-security-scan.yml` uses outdated action versions**: `github/codeql-action/upload-sarif@v2` should be `@v3`. `docker/build-push-action@v5` should be `@v6`. Low risk but breaks the "all actions use latest stable versions" DoD criterion.

4. **[US-E0-009] `test-deployment.yml` lacks top-level `permissions: read-all`**: Uses `permissions: contents: read, pull-requests: write` instead. This is functionally correct (grants minimal needed permissions) but does not match the literal DoD requirement. Low risk.

5. **[US-E0-010] Grafana sub-compose has hardcoded password fallback**: `monitoring/dashboard/grafana/docker-compose.grafana.yml:35` uses `${GRAFANA_ADMIN_PASSWORD:-admin}` which defaults to `admin`. The main monitoring compose correctly enforces the env var with `:?` validation. Fix: change `:-admin` to `:?` in the Grafana sub-compose.

1. **Prioritize test files** for the 3 FAIL items. These are well-contained, single-file middleware/routes that should reach 95%+ coverage with focused unit tests. Estimated effort: ~4 hours.
2. **Batch the action version updates** into a single commit updating `@v2` to `@v3` and `@v5` to `@v6` in `docker-security-scan.yml`.
3. **Fix the Grafana password fallback** in `grafana/docker-compose.grafana.yml` -- single-line change.
